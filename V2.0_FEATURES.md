# AgriMind AI v2.0 - Feature Documentation

## 📋 Quick Overview

AgriMind AI v2.0 introduces 4 major new features beyond the v1.0 price prediction system:

1. **🌾 Crop Recommendation Engine** - ML-powered multi-crop analysis
2. **🌦 Weather Integration** - Real-time weather & forecasting
3. **🤖 AI Farming Advisor** - Context-aware farming guidance
4. **📊 Agent-Based Decision Support** - Autonomous decision-making

All new features are accessible through both:
- **Web UI**: Tab-based interface in the React frontend
- **REST API**: JSON endpoints for programmatic access

---

## 1. 🌾 Crop Recommendation Engine

### Purpose
Analyzes climate conditions and recommends the most profitable crops to cultivate.

### How It Works
1. Takes climate parameters as input
2. Predicts prices for all supported crops
3. Calculates yield suitability scores based on climate fit
4. Computes profitability (price × yield × market demand)
5. Ranks crops by profitability score

### Input Parameters
```json
{
  "Region": "Colombo",              // Any Sri Lankan region
  "Temperature": 28,                // °C
  "Rainfall": 100,                  // mm
  "Humidity": 75,                   // %
  "CropYield": 50                   // Impact score (0-100)
}
```

### Output Example
```json
{
  "recommendations": [
    {
      "crop": "Tomato",
      "predicted_price": 245.50,
      "yield_suitability": 85.2,
      "expected_yield": 38.5,
      "market_demand": 90,
      "profitability_score": 945.23,
      "revenue_estimate": 9452.30,
      "reasoning": "High market price | Good climate fit | Strong demand"
    },
    // ... more recommendations
  ]
}
```

### API Endpoint
```
POST http://localhost:5000/recommend-crops
Content-Type: application/json

{
  "Region": "Colombo",
  "Temperature": 28,
  "Rainfall": 100,
  "Humidity": 75,
  "CropYield": 50
}
```

### Use Cases
- Choose between multiple crops
- Understand which crops are most profitable
- Compare crops based on market demand and yield
- Make informed planting decisions

## 4. 📊 Agent-Based Decision Support

### Purpose
Provides autonomous decision-making analysis through scenario planning and risk assessment.

### Scenario Analysis

#### Optimistic Scenario (20-25% probability)
- Best-case outcomes
- Favorable conditions assumed
- Higher price and yield predictions
- Useful for planning upside

#### Realistic Scenario (50-60% probability)
- Most likely outcomes
- Current predictions used as-is
- Best for financial planning
- Expected value calculation

#### Pessimistic Scenario (15-20% probability)
- Worst-case outcomes
- Adverse conditions assumed
- Lower price and yield predictions
- Risk planning

### Analysis Components

#### 1. Scenario Comparison
```json
{
  "scenarios": {
    "optimistic": {
      "predicted_price": 294.60,
      "estimated_revenue": 11384.50,
      "profit_per_hectare": 6830.70,
      "probability": "20-25%"
    },
    "realistic": {
      "predicted_price": 245.50,
      "estimated_revenue": 9452.30,
      "profit_per_hectare": 5671.38,
      "probability": "50-60%"
    },
    "pessimistic": {
      "predicted_price": 184.13,
      "estimated_revenue": 7101.23,
      "profit_per_hectare": 2460.74,
      "probability": "15-20%"
    }
  }
}
```

#### 2. Risk-Adjusted Return
- Expected profit value (weighted average)
- Confidence intervals
- Sharpe ratio (risk-adjusted return metric)
- Profit variability assessment

#### 3. Decision Matrix
Ranked comparison of top 5 crops with:
- Profitability scores
- Yield suitability percentages
- Price predictions
- Risk assessments
- Recommendation status

#### 4. Contingency Plans
For events like:
- Price drops (sell directly, add value, store)
- Pest/disease (IPM, biological controls)
- Adverse weather (drainage, irrigation)
- Market glut (pre-arrange sales, cooperatives)
- Input inflation (advance buying, alternatives)

#### 5. Sensitivity Analysis
Impact of variable changes:
- 10% price change → impact on profit
- 10% yield change → impact on profit
- 10% cost change → impact on profit
- Most sensitive variables identified

### API Endpoint
```
POST http://localhost:5000/decision-support
Content-Type: application/json

{
  "Region": "Colombo",
  "Temperature": 28,
  "Rainfall": 100,
  "Humidity": 75,
  "CropYield": 50
}
```

### Output Includes
- Scenario analysis (3 scenarios)
- Recommended strategy type (Conservative/Moderate/Aggressive)
- Risk-adjusted returns
- Decision matrix for crop selection
- Contingency plans for 5+ event types
- Sensitivity analysis
- Executive decision summary

### Use Cases
- Plan for different outcomes
- Assess financial risk
- Prepare contingency plans
- Make informed crop selection
- Understand profit variability
- Test assumptions (sensitivity analysis)

## 📊 Key Algorithms

### Profitability Scoring
```
Profitability = Price × Yield_Suitability × Base_Yield × Market_Demand
```

### Yield Suitability
```
Temp_Score = 100 - (|Temp - Optimal| × 5)    [0-100]
Rain_Score = 100 - (|Rain - Optimal| × 0.2)  [0-100]
Yield_Score = (Temp_Score × 0.6 + Rain_Score × 0.4) / 100  [0-1]
```

### Risk-Adjusted Return
```
Expected_Value = (Opt × 0.20) + (Real × 0.60) + (Pess × 0.20)
Variance = Σ(Scenario - Expected)² × Probability
Std_Dev = √Variance
Sharpe_Ratio = Expected_Value / Std_Dev
```

## 🔧 Troubleshooting

### Weather Data Not Available
- Check if region is in supported list
- Verify internet connection (uses OpenMeteo API)
- Use supported regions: Nuwara Eliya, Kandy, Colombo, etc.

### Models Missing Error
- Run `python train_model.py` in backend
- Ensure model files exist: model.pkl, region_encoder.pkl, veg_encoder.pkl

### CORS Errors
- Verify backend is running on port 5000
- Frontend should run on port 5173
- CORS is enabled by default in Flask

### Incorrect Recommendations
- Verify input data is within reasonable ranges
- Use sample data for testing first
- Check region and climate parameters
