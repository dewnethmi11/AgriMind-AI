# AgriMind AI

An AI agent that predicts vegetable prices, recommends crops, and helps farmers make data-driven decisions using climate and market data.

## Problem

Farmers often face uncertainty due to changing climate conditions and fluctuating vegetable prices. This makes it difficult to decide which crops to cultivate and when to grow them.

## Solution

AgriMind AI is an intelligent farming decision assistant that:

- Predicts vegetable prices
- Recommends suitable crops
- Analyzes climate conditions
- Provides AI-driven farming recommendations
- Visualizes market trends

## Features

- Vegetable price prediction
- Crop recommendation engine
- Climate-based insights
- Analytics dashboard
- AI farming advisor

## Technology Stack

### Frontend
- React
- Tailwind CSS
- Chart.js

### Backend
- Flask

### Machine Learning
- Pandas
- Scikit-Learn
- Random Forest Regressor

## Dataset

- 130,000 records
- 25 regions
- 20 vegetables
- Climate data (temperature, rainfall, humidity)
- Historical vegetable prices
